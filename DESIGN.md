# Profile design

A dark terminal-inspired banner with mint and lavender accents, followed by native GitHub Markdown sections. The banner and icons are stored locally; there are no runtime packages, remote image services, tokens, or scheduled workflows required.

## Research and credits

- [GitHub profile README documentation](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme): profile repository and README behavior.
- [Capsule Render](https://github.com/kyechan99/capsule-render): researched banner styles. The actual header is an original local SVG; no Capsule Render code or artwork is copied.
- [Skill Icons](https://github.com/tandpfun/skill-icons): technology icons downloaded from `https://skillicons.dev/icons?i=php,laravel,nextjs,ts,mysql,python,java,rust&theme=dark&perline=8`. MIT license preserved in `assets/skill-icons-LICENSE.txt`.

## Editing and publishing

- Edit text and project links in `README.md`.
- Edit banner text, colors, and shapes in `assets/header.svg`.
- Publish README.md and the assets directory together to the root of the public Nomos69/Nomos69 repository. Copying README.md alone will leave the images missing.
- The fixed dark banner appears in both GitHub light and dark modes; the surrounding Markdown follows the reader's GitHub theme.
- Rust is explicitly labeled as a learning focus, not a proficiency claim.
